# Датасет закупок

SKU — четыре Excel-файла с характеристиками. Неустановленные значения не означают отсутствие характеристики.

tenders — десять закупок в перемешанном порядке. Номера закупок сохранены. Все сохранённые вложения выбранных пакетов скопированы побайтно, без конвертации. XML включён там, где он есть в исходном пакете. Имена дополнены порядковым префиксом, чтобы не потерять одноимённые файлы. Расширения сохранены по исходным именам и могут отличаться от фактического формата.

Пакет собран из сохранённых локальных источников. Для шести закупок использованы ранние выгрузки ЕИС, для четырёх — архив API. Полнота относительно текущего сайта не подтверждена. SHA-256 и фактические форматы — в manifest.json.

В трёх исходных пакетах вместо одного из документов сохранён ответ об ошибке. Эти байты оставлены без изменений; это пробелы комплекта:

- tenders/02_0373200087824002359/09_Электронный документ, полученный из внешней системы.docx
- tenders/05_0119200000124020697/08_Электронный документ, полученный из внешней системы.docx
- tenders/06_0319200068624000142/10_Электронный документ, полученный из внешней системы.xml
